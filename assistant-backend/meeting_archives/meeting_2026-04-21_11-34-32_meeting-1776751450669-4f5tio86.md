### Code Implementation (Optimal Approach)

```javascript
function arrayToNestedArray(arr) {
  return arr.map(item => [item]);
}

// Example Usage (MANDATORY)
console.log(arrayToNestedArray([1, 33, 5])); // Output: [[1], [33], [5]]

// Complexity & Strategy
// Time Complexity: O(n), where n is the length of the input array. We iterate over each element once.
// Space Complexity: O(n), as we create a new array with the same number of elements.

### Step-by-Step Walkthrough

1. The function `arrayToNestedArray` takes an array `[1, 33, 5]` as input.
2. It uses the `map` method to iterate over each element in the array.
3. For each element, it creates a new sub-array containing just that element `[item]`.
4. The result is a new array of arrays: `[[1], [33], [5]]`.

This approach efficiently converts the input array into the desired nested array format with a time complexity of O(n) and a space complexity of O(n).
